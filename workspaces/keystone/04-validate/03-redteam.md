## 一句话定位

> **新加坡AI简历优化工具：针对特定职位匹配 + 追踪投递效果，积累新加坡市场独有的求职数据护城河。**

---

## 产品概述

| 维度 | 内容 |
|------|------|
| **核心功能** | 简历-Job匹配度分析 + 逐行修改建议 + Outcome追踪 |
| **目标用户** | 新加坡求职者（B2C），长期包含大学/机构（B2B） |
| **市场定位** | 新加坡首个"结果导向"简历优化工具 |
| **差异化** | Outcome数据 + 新加坡特定（GLC/MNC/NS） |

---

## MVP功能（Phase 1）

```
输入：
├── 上传简历（PDF/Word/Text）
└── 粘贴Job URL或文字

输出（前端）：
├── 整体匹配度（65%可视化）
├── 技能匹配详情（强/可迁移/缺失）
├── 修改建议（3-5条，可采纳/编辑）
├── 简历编辑区
├── 导出PDF/Word
└── Outcome追踪（投递后记录结果）
```

**不包括**：RAG、Bandit、预测模型（这些是Phase 2-3）

## 数据策略

### 数据护城河

```
用户数据 → AI更好 → 用户更多 → 更多数据
     ↑
   12-18个月积累才能形成差异化
```

### 数据优先级

| 优先级 | 数据 | 何时收集 |
|--------|------|---------|
| 最高 | Outcome追踪 | MVP阶段 |
| 最高 | 建议采纳/拒绝 | MVP阶段 |
| 中等 | 用户行为 | Phase 2 |

### 冷启动

```
Day 1: Build MVP
Day 30: Launch（无RAG，直接LLM生成）
Day 90: 数据够 → 激活RAG
Day 180: 数据更多 → 激活Bandit
```
