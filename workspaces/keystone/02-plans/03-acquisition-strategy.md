# 获客策略：第一个100用户计划

## 目标

```
Month 1：获取第一个100注册用户
Month 3：获取第一个1,000注册用户
Year 1：获取2,000-3,000注册用户
```

---

## 第一阶段：冷启动（Month 1）

### 目标：100个早期用户

**核心策略：口碑 + 职业教练合作**

#### 1. 职业教练合作（最高优先级）

**为什么**：职业教练的用户 = 高意向求职者 = 最有可能付费

**做法**：
```
- 联系5-10个新加坡职业教练
- 提供：免费1年Pro账号（给教练用）+ 推荐费（$10/人）
- 教练推荐客户使用KeyStone
- 客户获得：免费1个月Pro（通过教练推荐码）
```

**成本估算**：
- 10个教练 × 1年Pro = $1,440/年
- 推荐费：100用户 × $10 = $1,000
- **总成本：~$2,500**

#### 2. LinkedIn个人网络

**做法**：
```
- 创始人LinkedIn发帖
- 内容：分享找工经历 + "我正在做一个工具"
- 不广告，纯故事
- 附：内测邀请链接
```

**目标**：通过个人网络获取20-30用户

#### 3. Reddit r/singapore（内容营销）

**做法**：
```
- 不发广告帖
- 在求职相关帖子下提供价值
- 例如："我刚找到工作了，分享一下我的方法..."
- 自然提到KeyStone
```

**注意**：需要提前4-6周养号

---

## 第二阶段：增长（Month 2-3）

### 目标：1,000注册用户

**核心策略：Referral + 内容营销**

#### 1. Referral机制（最高优先级）

**为什么**：低成本、高质量、口碑传播

**方案**：
```
用户推荐朋友注册：
- 推荐人：获得1个月免费Pro
- 被推荐人：获得3次免费分析

当被推荐人升级Pro：
- 推荐人：获得$10积分
```

**预期**：
- 100早期用户 × 30%参与率 = 30人推荐
- 30人 × 平均2个推荐 = 60个新用户
- **Referral贡献：60-100新用户**

#### 2. 职业教练批量合作

**做法**：
```
- 每月与2-3个新教练建立合作
- 提供：教练专属后台 + 客户追踪功能
- 教练推荐客户使用
```

**预期**：每个教练带来10-20个用户
**目标**：Month 2合作5个教练

#### 3. 小红书/微信内容

**新加坡华人市场**：
```
- 小红书：发布"新加坡找工作简历技巧"
- 微信群：职业相关社群
- 内容价值为主，品牌植入为辅
```

**预期**：每月20-30新用户

---

## 第三阶段：规模化（Month 4-12）

### 目标：2,000-3,000注册用户

**核心策略：B2B带动B2C**

#### 1. 大学职业中心B2B

**为什么**：一个大学 = 批量用户 + 口碑传播

**做法**：
```
- Month 4-6：与1-2所大学谈试点
- 提供：免费1学期 + 职业中心管理后台
- 数据：试点效果
- Month 9+：谈正式合同
```

**预期**：
- 每所大学：200-500个学生用户
- 2所大学 = 400-1,000个用户

#### 2. 机构合作

**目标**：Recruitment Agency

**为什么**：Agency的候选人 = 高意向 = 最可能付费

**做法**：
```
- 联系10家 boutique recruitment agencies
- 提供：候选人工具白标
- Agency推荐候选人使用
```
