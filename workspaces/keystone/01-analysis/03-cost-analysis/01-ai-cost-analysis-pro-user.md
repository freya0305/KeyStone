## 三、逐项成本计算

### MVP阶段（Phase 1）：无优化版本

**场景**：用户上传一份简历 + 分析5个Job + 每个Job生成5条建议

```
简历解析（Haiku）：
- 输入：简历文字约2000 tokens
- 输出：结构化JSON约500 tokens
- 成本：$0.00125 × 2.5 + $0.005 × 0.5 = $0.005（约¥0.04）

Job解析（Haiku）：
- 输入：Job描述约1500 tokens
- 输出：结构化要求约300 tokens
- 5个Job：$0.003 × 5 = $0.015

匹配分析（Haiku分类）：
- 输入：简历+Job比较约500 tokens
- 输出：4级评估 + 解释约300 tokens
- 5个Job：$0.004 × 5 = $0.02

建议生成（Sonnet）：
- 每个Job生成5条建议，每条约400 tokens
- 输入：简历行+Job+上下文约600 tokens
- 输出：每条建议约200 tokens
- 5个Job × 5条 = $0.09

─────────────────────────────────────────
总计：$0.005 + $0.015 + $0.02 + $0.09 = $0.13/用户/次分析

每月按8次分析：$0.13 × 8 = $1.04/月/Pro用户
```

**结论**：Phase 1无优化成本 = **$1.04/月/Pro用户**

---

### Phase 2：优化版本（6个月后，有缓存）

**假设**：70% Job解析命中缓存，50%建议命中缓存

```
简历解析（不缓存，每次都是新的）：$0.005 × 8次 = $0.04
Job解析（70%命中）：$0.015 × 8 × 30% = $0.036
匹配分析（不缓存）：$0.02 × 8 = $0.16
建议生成（50%命中RAG）：
- 实际调用AI：8 × 5 × 50% = 20条建议 × $0.018 = $0.36

─────────────────────────────────────────
总计：$0.04 + $0.036 + $0.16 + $0.36 = $0.60/月/Pro用户
```

**结论**：Phase 2优化成本 = **$0.60/月/Pro用户**

---

### Phase 3：完全体（12个月后，有模型）

**假设**：Bandit排序、预测模型介入，AI只处理20%的新情况

```
简历解析：$0.005 × 8 = $0.04
Job解析（90%命中）：$0.015 × 8 × 10% = $0.012
匹配分析（模型做，不用AI）：$0.02 × 8 × 20% = $0.032
建议生成（80%走数据库）：
- AI调用：8 × 5 × 20% = 8条建议 × $0.018 = $0.144

─────────────────────────────────────────
总计：$0.04 + $0.012 + $0.032 + $0.144 = $0.23/月/Pro用户
```

**结论**：Phase 3模型版本成本 = **$0.23/月/Pro用户**

## 八、结论

### AI成本完全可以Cover $12 Pro定价

```
Phase 1（现在）：$1.04/人/月，毛利率 91%
Phase 2（6个月）：$0.60/人/月，毛利率 95%
Phase 3（12个月）：$0.23/人/月，毛利率 98%
```

**最坏情况**（月活30次海投用户）：
- AI成本 $3.90/月
- 毛利率仍有 68%
- 还是赚钱的

### 真正的成本风险在哪里？

**不是AI成本，是获客成本（CAC）**

| CAC | 月流失率 | LTV | 回本周期 |
|-----|---------|-----|---------|
| $20 | 10% | $36 (3个月) | 第4个月回本 |
| $50 | 10% | $36 | 永远不回本 ❌ |
| $100 | 10% | $36 | 永远不回本 ❌ |

**结论**：$12/月的定价对AI成本是OK的。
**真正的风险**：获客成本能否控制在$20以内。
