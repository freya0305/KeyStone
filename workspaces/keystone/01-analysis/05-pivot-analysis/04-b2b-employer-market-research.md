## 一、现有竞品分析

### 竞品一览

| 工具 | 定位 | 目标用户 | 定价 | 备注 |
|------|------|---------|------|------|
| **Jobalytics** | 简历→JD匹配 | 求职者 | 免费 | Chrome插件，只做ATS优化 |
| **Textio** | JD去偏见化 | 企业HR | 不公开 | 大企业为主，强调inclusive hiring |

### 现有竞品弱点

```
1. 没有"根据候选人特征生成JD"的工具
2. 没有"学习市场成功简历反推JD"的功能
3. 没有专门针对新加坡市场的工具
4. 小型企业（10-50人）几乎没有选择
```

## 二、目标用户细分

### 潜在目标用户

| 用户类型 | 规模 | JD痛点 | 付费意愿 | 优先级 |
|---------|------|--------|---------|--------|
| **小微创业公司** | 1-10人 | 没有HR，自己写，写的差 | 低（省钱） | ⚠️ 待定 |
| **小型企业** | 10-50人 | 偶尔招人，不专业 | 中 | ✅ **主要目标** |
| **中型企业** | 50-200人 | 有HR，但效率低 | 中高 | ✅ **主要目标** |
| **猎头/recruitment** | 不限 | 大量JD要写 | **高** | ✅ **最高** |
| **大企业** | 200+人 | 有专业HR，不需要 | 低 | ❌ |

### 猎头/Recruitment为什么是最好的目标

```
猎头的痛点：
1. 每天要写大量JD（10-50个/天）
2. 每个职位需要针对不同公司定制
3. 写JD是体力活，但没有技术含量
4. 写完还要找匹配的简历，工作量巨大

猎头的付费意愿：
- 效率就是钱：少花1小时写JD = 多找1个候选人 = 可能成一单
- 猎头一单佣金通常是候选人年薪的20-25%
- 1个候选人 = $2,000-10,000佣金
- 所以1小时JD时间价值 = $50-250

结论：猎头愿意为能节省时间的工具付钱
```

## 三、定价模型分析

### 定价逻辑

```
定价参考：

1. 效率价值定价：
   - 如果工具能节省猎头每天1-2小时写JD的时间
   - 1小时价值 = $50-250（取决于候选人薪资）
   - 每天节省$50-250 × 20个工作日 = $1,000-5,000/月
   - 所以定价$29-99/月是合理的（投资回报率极高）

2. 市场竞争定价：
   - 招聘SaaS月费：$20-100/人
   - ATS工具月费：$50-200/人
   - JD工具：目前没有强竞争者

3. 按价值定价（Value-based）：
   - 帮猎头多做成1单 = $2,000-10,000
   - 工具帮你省的时间价值 = $1,000-5,000/月
   - 所以$99-299/月是合理的价格区间
```

### 建议定价方案

| 产品 | 定价 | 用户数 | 功能 |
|------|------|--------|------|
| **猎头基础版** | **$49/月** | 1人 | 每月50个JD生成 |
| **猎头专业版** | **$129/月** | 1人 | 无限JD + 候选人画像 |
| **猎头团队版** | **$299/月** | 5人 | 团队协作 + API |
| 小型企业版 | $29/月 | 1人 | 每月20个JD |

**说明**：定价需要实际验证，这些只是基于逻辑的估算。

## 四、猎头市场具体分析

### 猎头在新加坡

```
新加坡猎头市场：
- 约有500-800家recruitment agencies
- 其中200-300家是做Tech/Finance等PMET职位的
- 每家猎头公司有5-50个recruiters
- 每个recruiter每月处理20-50个职位

Target用户估算：
- 主要目标：50-100人规模的中型猎头
- 次要目标：10-30人规模的小型猎头
- 市场容量：约500-1,000家公司
```

### 猎头的具体痛点

```
1. "我每天要写10个JD，每个要30分钟 = 5小时"
   → 工具能做什么：5分钟生成初稿，人工修改

2. "我不知道这个职位市场上有多少人在投"
   → 工具能做什么：分析公开简历数据，告诉你竞争程度

3. "我不知道JD写的够不够好，能不能吸引到人"
   → 工具能做什么：基于历史数据预测投递率

4. "我要针对每个公司定制JD，不能用通用模板"
   → 工具能做什么：学习公司风格，生成定制化JD
```

## 五、小型企业分析

### 小型企业（10-50人）

```
痛点：
- 没有专门HR，或者HR兼着很多事
- 写JD是"临时任务"，不专业
- 不知道怎么写才能吸引到人

付费意愿：
- $29-49/月 是可以接受的（如果真的有用）
- 但需要证明ROI：招到一个人 = $1,000-10,000

市场容量：
- 新加坡10-50人企业：约10,000-20,000家
- 其中需要招人的比例：约30%
- 可触达目标：3,000-6,000家
```

### 小型企业的挑战

```
挑战：
1. 认知度低：不知道好的JD长什么样
2. 信任度低：对工具生成的JD不放心
3. 决策周期长：需要说服老板/HR head

建议：
- 先做猎头，因为他们痛点更强、付费意愿更高
- 猎头验证后再拓展到小型企业
```

## 六、竞争对手空白

### 现有工具的定位

```
Jobalytics：帮求职者优化简历（不是帮雇主写JD）
Textio：帮大企业做inclusive JD（不是帮猎头）
LinkedIn：招聘管理平台（JD只是很小的一部分）
模板网站：通用模板（无AI，无个性化）

结论：
在"帮猎头/小型企业快速生成定制化JD"这个细分市场
几乎没有直接竞品！
```

### KeyStone的差异化

```
其他工具：
- Jobalytics = 简历优化（求职者用）
- Textio = inclusive JD（大企业用）
- LinkedIn = 招聘平台（管理用）

KeyStone JD优化：
- 帮雇主（猎头/小型企业）写更好的JD
- 基于公开简历数据学习什么是"好简历"
- 反推生成更吸引人的JD
- 这是市场空白！
```

## 八、最重要的发现

### 竞品分析结论

```
市场空白：
"帮猎头/小型企业快速生成定制化JD"的工具
这个细分市场几乎没有直接竞品！

现有工具的问题：
- Jobalytics：面向求职者，不适合雇主
- Textio：面向大企业，不适合猎头/小型企业
- LinkedIn：平台太大，JD只是附加功能
- 模板网站：太简单，无AI，无个性化
```

### 定价建议

```
猎头用户（最高优先级）：
- $49-129/月 是合理区间
- 基于：每天节省1-2小时 = $50-250价值

小型企业（次优先级）：
- $29-79/月 是合理区间
- 基于：省时 + 招到人的ROI

建议先用猎头验证，因为：
1. 痛点更强（每天写大量JD）
2. 付费意愿更高（效率=钱）
3. 决策更快（recruiter自己就能决定）
```
