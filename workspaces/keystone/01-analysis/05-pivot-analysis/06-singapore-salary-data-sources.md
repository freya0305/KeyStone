## 一、主流数据源对比

### 1.1 政府数据（免费/低成本）

| 来源 | 数据类型 | 覆盖 | 成本 | API可用性 | 备注 |
|------|---------|------|------|-----------|------|
| **MOM 劳动力市场数据** | 行业平均薪资、职位分布、雇佣趋势 | 全面 | 免费 | ❌ 无公开API | 年度/季度报告，数据有延迟 |
| **SkillsFuture** | 技能薪资对应表 | 有限 | 免费 | ❌ 无 | 主要用于培训决策 |
| **Labour Market Insights** | 职位空缺、薪资中位数 | 中等 | 免费 | ⚠️ 部分 | MOM下属，数据较新 |

**评估**：政府数据权威但滞后（通常1-2年），无实时API，适合做基准而非实时参考。

| **Glassdoor** | 中等 | 中等 | ❌ 无公开API | 免费 | 样本量有限 |
| **JobStreet** | 大量 | 较好 | ⚠️ 有限合作 | 需谈合作 | 主要面向招聘方 |

## 三、可行的技术方案

### 方案A：爬虫 + 清洗（低成本）

```
数据来源：
1. JobStreet（公开职位薪资范围）
2. MyCareersFuture（政府平台，数据公开）
3. LinkedIn（需登录，但可访问）
4. Indeed（薪资标签）

技术实现：
- 定期爬取（每周/每月）
- 清洗 + 结构化
- 存储到PostgreSQL
- 作为Claude Prompt上下文

成本：开发时间（1-2周）
风险：反爬虫、IP封禁、法律风险
法律风险：爬取商业平台存在法律灰色地带
```

### 方案B：招聘平台合作（中等成本）

```
合作对象：
1. JobStreet (新加坡最大招聘平台)
2. MyCareersFuture (政府平台，更容易谈)

合作方式：
- 数据API接入（通常需要招聘方账号）
- 数据共享协议
- 联合产品（"基于XXX数据的薪资建议"）

成本：
- JobStreet: 需企业账号（$500+/月起）
- MCFD: 可能免费（政府合作项目）
```

### 方案C：众包 + 人工维护（适合早期）

```
方式：
1. 用户提交薪资数据（换算成tokens/积分）
2. 人工验证 + 结构化
3. 公开感谢数据贡献者

工具：
- Typeform / Google Form 收集
- Airtable 存储
- 人工审核

优点：
- 成本低
- 数据真实
- 用户参与感

缺点：
- 数据积累慢（冷启动问题）
- 需要人工维护
- 覆盖不全面
```

### 方案D：招聘公司年度报告 + LLM提取

```
步骤：
1. 收集公开的薪资报告（PDF）
2. 用LLM提取关键数据
3. 存储到结构化数据库
4. 定期更新

可用的报告：
- Robert Walters Salary Survey 2025/2026
- Michael Page Salary Guide Singapore
- Robert Half Asia Salary Guide
- Adecco Salary Guide

频率：每年更新一次
数据延迟：1年左右
```

## 四、推荐方案（分阶段）

### Day 1 MVP：无实时薪资数据

```
v1 MVP不建议包含市场薪资数据，原因：
1. 数据获取成本高（API合作/爬虫开发）
2. 法律风险（爬虫可能违规）
3. 用户不一定会用这个功能
4. 竞品没有实时薪资数据也能用

替代方案：
- 用LLM根据职位名称 + 经验生成"合理薪资范围"
- 标注"基于市场数据估算"
- 用户反馈可帮助后续改进
```

### v2：整合公开报告

```
数据来源：
1. Robert Walters Salary Survey 2026（免费PDF）
2. Michael Page Salary Guide 2026（免费PDF）
3. 人工提取关键数据
4. 存储到数据库

覆盖：
- Tech: Software Engineer, Data Scientist, Product Manager
- Finance: Accountant, Financial Analyst, Finance Manager
- Sales: Sales Executive, Account Manager

更新频率：每6个月
数据精度：区间估算（低/中/高）
```

### v3：招聘平台合作

```
目标：
- JobStreet API接入
- MyCareersFuture数据合作

时机：
- 有一定用户量后（50+付费用户）
- 可以展示合作价值

预计成本：
- JobStreet: $500-2000/月（企业账号）
- MCFD: 可能免费
```

## 六、结论与建议

### 核心发现

```
1. 新加坡没有免费、公开、高质量的实时薪资API
2. 招聘平台（JobStreet, LinkedIn）有数据但不对外开放
3. 商业数据（Mercer等）质量高但价格昂贵（$10k+/年）
4. 猎头公司年度薪资报告是免费数据的好来源
5. 爬虫有法律风险，不建议在MVP阶段使用
```

### MVP阶段建议

```
不包含实时薪资数据，改用：
1. LLM估算 + 标注"估算值"
2. 猎头报告数据做参考（每6个月更新一次）
3. 用户可反馈实际数值（众包）
```

### v2阶段建议

```
优先合作 MyCareersFuture（政府平台）：
1. 数据较准确
2. 可能愿意合作（推动就业市场透明化）
3. 政治正确性

次选：JobStreet企业账号
```
