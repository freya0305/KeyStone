# KeyStone 双侧市场分析：从B2C到B2B2C

## 核心洞察

```
原本：帮求职者找工作
  ↓ 痛点：没有数据，冷启动难，付费意愿低

现在：帮雇主写JD + 帮求职者写简历
  ↓ 解决：双向数据飞轮，公司付钱，数据自给自足
```

## 二、双侧价值流

### 数据来源（不再依赖用户隐私数据）

```
公开简历数据：
├── LinkedIn简历（公开可见）
├── JobStreet候选人简介
├── MyCareersFuture简历
└── 求职者自愿上传（激励：更好的JD匹配）

公开JD数据：
├── MyCareersFuture
├── JobStreet
├── LinkedIn Jobs
├── company career pages
└── 雇主自愿发布（激励：更好的候选人匹配）
```

**关键区别**：数据是公开的，不涉及隐私问题！

---

### 价值创造

```
对雇主（公司）：
输入：我想招一个Senior Python Engineer
输出：
├── 好的JD模板（基于历史成功简历反推）
├── 薪酬建议（市场参考）
└── 候选人画像（什么特征的人成功率最高）

对求职者：
输入：我想申请这个JD
输出：
├── 简历修改建议（基于JD特征）
├── 匹配度分析
└── 被捞概率预测
```

## 三、商业模式彻底改变

### 旧模式（B2C为主）

```
收入：个人用户 $12/月
问题：转化率低，付费意愿低
护城河：用户outcome数据（需要时间积累）
```

### 新模式（B2B为主）

```
收入来源：
├── 雇主订阅（写JD）：$99-499/月
├── 雇主招聘套餐：按候选人数量计费
├── 求职者增值服务（免费基础+付费高级）
└── 数据授权（匿名化数据给HR研究机构）
```

### B2B定价初步估算

| 产品 | 价格 | 目标客户 |
|------|------|---------|
| JD优化订阅 | $99/月 | SMB（中小企业） |
| JD + 候选人匹配 | $299/月 | 中型企业 |
| 企业定制 | $999+/月 | 大企业/猎头 |
| 简历曝光套餐 | $19/次 | 求职者 |

## 四、数据飞轮完全改变

### 旧飞轮（冷启动难）

```
用户数据 → AI更好 → 更多用户
   ↑
 慢（6-18个月才能差异化）
```

### 新飞轮（冷启动快）

```
公开数据（Day 1就有）
   │
   ▼
分析公开简历 + JD → 学习什么组合成功
   │
   ▼
平台上线 → 雇主/求职者加入
   │
   ▼
更多公开数据 + 用户数据 → AI更好
   │
   ▼
更精准的匹配 → 更多的用户/雇主
```

**关键区别**：不需要等用户数据！公开数据Day 1就可以开始训练。

## 五、竞争力分析

### 新护城河

| 护城河 | 强度 | 时效 |
|--------|------|------|
| **JD-简历匹配 intelligence** | 最强 | 越积累越强 |
| **公开数据资产** | 强 | 可复制但需要时间 |
| **双向网络效应** | 最强 | 公司多→求职者多→公司更多 |
| **雇主订阅收入** | 中 | 需要销售能力 |

### 竞争对手能否复制？

| 竞争对手 | 复制难度 | 说明 |
|----------|---------|------|
| LinkedIn | 高 | 已有数据，但JD优化不是重点 |
| VMock | 中 | 大学市场，但只有简历 |
| Teal | 中 | B2C思维，转型B2B难 |
| 招聘平台 | 低 | 已有JDs，但不做匹配 |

**关键洞察**：没有人同时拥有"简历数据"+"JD数据"+"匹配 intelligence"，这是空白市场。

## 六、执行路径

### Phase 1：JD优化（公司端）

```
目标：先让公司愿意付钱

产品：
├── 输入：职位描述（粗糙的）
├── 输出：优化后的JD
│   ├── 更好的职位描述
│   ├── 薪酬市场参考
│   └── 候选人画像
└── 价格：$99-299/月

数据收集：
├── 雇主发布JD → 收集
├── 公开简历数据 → 分析
└── 学习什么JD吸引了好的候选人

Day 1就可以开始（公开数据）
```

### Phase 2：简历匹配（求职者端）

```
产品：
├── 输入：用户简历 + 目标JD
├── 输出：
│   ├── 匹配度分析
│   ├── 简历修改建议
│   └── 被捞概率
└── 价格：免费基础 + $12/月Pro

数据收集：
├── 公开简历 + JD
└── 用户行为（哪些JD被投递，哪些简历被查看）
```

### Phase 3：双向智能

```
平台成熟后：
├── JD发布 → 自动推荐匹配的简历
├── 简历上传 → 自动推荐匹配的JD
└── 双向匹配算法 → 核心差异化
```
