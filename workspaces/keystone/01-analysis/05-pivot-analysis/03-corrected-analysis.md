# KeyStone 纠错分析：工具定位 + B2B定价

## 用户澄清

```
用户明确：
1. ✅ B2B为主要收入
2. ❌ 不做简历匹配平台（像LinkedIn）
3. ❌ 定价99-499没有依据，需要重新验证
4. ✅ 有B2B销售能力

产品定位（工具，不是平台）：
├── 雇主：输入需求 → 优化JD
└── 求职者：输入JD → 优化简历
```

---

## 产品定位（工具，不是平台）

### 雇主端（核心收入）

```
产品：JD优化工具

用户输入：
├── 职位名称（Senior Software Engineer）
├── 必须技能（Python, AWS）
├── 经验要求（5+年）
├── 薪资范围（可选）
└── 公司类型（Startup/GLC/MNC）

系统输出：
├── 优化后的JD（更吸引人的描述）
├── 候选人画像（什么样的人适合）
├── 薪酬建议（市场参考，可选）
└── JD效果预测（预计投递人数）

不做什么：
❌ 简历库搜索
❌ 候选人匹配
❌ 招聘流程管理
```

### 求职者端（用户获取 + 数据）

```
产品：简历优化工具（原有功能）

用户输入：
├── 简历（PDF/Word）
└── 目标JD（URL或文字）

系统输出：
├── 匹配度分析
├── 修改建议（针对这个JD）
└── 简历导出

不做什么：
❌ 简历库曝光
❌ 主动投递
❌ 职位推荐
```

## 目标用户分析

### 雇主端（需要你验证）

| 用户类型 | 规模 | 痛点 | 付费意愿 | 优先级 |
|---------|------|------|---------|---------|
| 小微创业公司 | 1-10人 | 没有HR，自己写 | 低（省钱优先） | 待定 |
| 小型企业 | 10-50人 | 有时写JD，不专业 | 中 | **主要目标** |
| 中型企业 | 50-200人 | 有HR，但质量一般 | 中高 | **主要目标** |
| 猎头/recruitment | 不限 | 大量JD要写 | 高（效率就是钱）| **最高** |
| 大企业 | 200+ | 专业HR，不需要 | 低 | ❌ |

**初步判断**：猎头/recruitment agency 可能是最好目标用户
- 痛点强：每天写大量JD
- 付费意愿高：效率=钱
- 但需要验证

### 定价需要你验证

```
关键问题：
1. 现在猎头/小型企业怎么解决JD问题？
   - 自己写（没工具）
   - 用模板（Generic）
   - 找人写（贵）

2. 如果有一个工具能帮他们写出更好的JD，他们愿意付多少？
   - $19/月？（按量算）
   - $49/月？（月费订阅）
   - $299/月？（企业级）

3. 市场上类似工具的价格是多少？
```

## 数据飞轮（不变）

```
公开简历数据 → 训练模型
        ↓
   分析什么简历成功率高
        ↓
   生成更好的JD建议（雇主端）
        ↓
   优化简历建议（求职者端）
        ↓

```
