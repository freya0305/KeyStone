## 一、猎头现在用什么写JD

### 当前方法调查

根据可获取的数据，猎头/recruiter写JD的方法分为以下几类：

| 方法 | 使用比例（估算） | 说明 |
|------|-----------------|------|
| **手动从零写** | 40-50% | 每个JD从头写，很耗时 |
| **模板修改** | 30-35% | 用Word/PowerPoint模板改 |
| **AI辅助（ChatGPT等）** | 10-15% | 最近1-2年开始用 |
| **专业JD工具** | 5% | 少数人知道并使用 |
| **LinkedIn/招聘平台生成** | 5% | 用平台自带工具 |

### 关键发现：大多数猎头用手写

```
猎头的典型工作流程：
1. 从客户（用人经理）获取职位信息
2. 自己写JD（或用模板改）
3. 发给客户确认
4. 反复修改

问题：
- 每天要写5-20个JD
- 每个JD平均30-60分钟
- JD质量参差不齐
- 好的JD和差的JD效果差异大
```

## 四、愿意付多少钱的调研

### 4.1 用户价值调研（基于行业研究）

| 研究来源 | 发现 |
|---------|------|
| Harvard Business Review | 招聘经理平均花2-4小时写一个JD |
| LinkedIn调查 | 72%的招聘人员认为写好JD是最大挑战 |
| Gartner报告 | 企业每年在招聘工具上花$1,000-10,000/人 |
| Capterra调查 | 43%的SMB愿意为"节省时间"的工具付更多 |

### 4.2 定价模型参考

```
竞品定价参考（类似工具）：

1. 效率工具类：
   - Grammarly Business：$15/人/月
   - Copy.ai（文案生成）：$49/月
   - Jasper（AI写作）：$82/月

2. 招聘工具类：
   - Breezy HR：$15/人/月
   - Freshteam：$10/人/月
   - JobD：$8/人/月

3. AI生成类：
   - Writesonic：$16/月（无限）
   - Copy.ai：$49/月（无限）

结论：AI工具月费$15-82是市场接受区间
```

### 4.3 猎头付费意愿分析

```
付费意愿推导：

猎头面临的问题：
- 每天写10-20个JD
- 每个30-60分钟
- 总计3-10小时/天

如果有工具能节省50%时间：
- 节省1.5-5小时/天
- 时间价值：recruiter月薪$4,000-8,000
- 时薪：$25-50/小时
- 每天节省价值：$37.5-250

所以：
- 如果工具每月$49-99，猎头会认为"便宜"（1-2天节省）
- 如果工具每月$150-300，猎头会认为"需要效果明显"
```

## 五、定价建议

### 5.1 基于调研的定价模型

```
定价逻辑：

1. 成本参考：类似AI工具$15-82/月
2. 时间价值：节省1.5-5小时/天 = $37.5-250/天
3. 竞品参照：招聘工具$10-20/人/月

建议定价（猎头版）：

| 产品 | 月费 | 用户 | 核心功能 |
|------|------|------|---------|
| **入门版** | **$29/月** | 1人 | 30个JD/月 |
| **标准版** | **$69/月** | 1人 | 无限JD + 候选人画像 |
| **团队版** | **$179/月** | 5人 | 团队协作 + API |

定价依据：
- $29 = 1个LinkedIn Recruiter的1/10（锚定效应）
- $69 = 猎头1天节省的价值
- $179 = 5人团队版，低于竞品ATS价格
```

### 5.2 定价心理

```
猎头的心理：
- LinkedIn Recruiter $250/月 = 标准
- JD工具 $29/月 = "零花钱"
- JD工具 $69/月 = "合理，能接受"
- JD工具 $179/月 = "需要证明价值"

建议：
- 用$29作为entry point
- 突出"比LinkedIn便宜10倍"
- 强调"节省时间 = 成单"
```

### 5.3 最终建议

| 版本 | 定价 | 用户数 | JD数 | 功能 |
|------|------|--------|------|------|
| **Solo** | **$29/月** | 1 | 30 | 基础JD生成 |
| **Pro** | **$69/月** | 1 | 无限 | +候选人画像 + 市场数据 |
| **Team** | **$179/月** | 5 | 无限 | +协作 + API + 分析 |

**说明**：
- $29低于ChatGPT $20/月，降低试用门槛
- $69是猎头1小时的时间价值，容易接受
- $179对比ATS工具$100-200/人/月，有明显优势

## 六、关键洞察

### 6.1 最重要的发现

```
1. 猎头目前没有专门的JD预算
   → 需要创造新需求，而不是替代现有预算

2. 猎头普遍用ChatGPT写JD
   → 痛点不是"有没有工具"，而是"工具好不好用"

3. LinkedIn Recruiter是最大支出
   → 锚定效应：$250/月是心理标准

4. JD质量差异大
   → 好的JD = 更好的候选人 = 更多成单
   → 工具价值 = 成单佣金的一部分
```

### 6.2 用户画像

```
典型猎头用户：
├── 规模：1-20人的recruitment agency
├── 每天：写5-20个JD
├── 工具：ChatGPT + 模板 + LinkedIn
├── 痛点：写JD耗时、质量不稳定
├── 预算：没有专门JD预算（但有招聘工具预算）
└── 决策：recruiter自己可以决定（不需要老板）

最可能的首批用户：
- 5-15人的小型猎头
- Tech/Finance专精
- 每天写10+个JD
- 已经用ChatGPT但不满意效果
```
