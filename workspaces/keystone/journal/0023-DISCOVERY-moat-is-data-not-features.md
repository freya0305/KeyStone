# Journal 0023 — DISCOVERY: The Product IS the Distribution Mechanism

**Date**: 2026-04-29
**Type**: DISCOVERY
**Triggered by**: Point 3 (unique moat analysis) and Point 9 (how to win vs Teal)

---

## Discovery

KeyStone's core strategic error is treating the resume tool as the product and the data as a side effect.

**The correct framing**: The resume tool IS the distribution mechanism for gathering the data. The actual product is the SG-specific outcome data corpus.

Why this matters:
- If the tool is the product: we must make money from subscriptions
- If the data is the product: we must maximize users and outcome logging, even at the expense of short-term revenue

**The moat is NOT**:
- SG-specific features (copyable in weeks)
- URL parsing (trivial to replicate)
- Four-level gap framework (design choice, not barrier)
- NS framing rules (one week's work for any competitor)

**The moat IS**:
- The SG outcome data corpus accumulated over 12-18 months
- The institutional B2B contracts creating switching costs
- The feedback loop: more users → more data → better suggestions → more users

**Teal's structural vulnerability**: Teal faces a cold-start trap. To truly match KeyStone's moat, Teal needs thousands of SG users logging outcomes for 12-18 months — before which they have no data to calibrate on. Teal can copy every feature in weeks. They cannot copy outcome data they don't have.

**The uncomfortable truth**: The first 90 days should NOT be spent on feature development. They should be spent signing a university pilot, because only institutional channels can generate outcome data at the speed required to build the moat before Teal decides SG is worth prioritizing.

---

## Why This Is Actionable

This changes the priority order:

Before: Build features → launch B2C → acquire users
After: Sign university pilot → build outcome tracking UX → acquire users through pilot spillover

---

## Implication for User

The user (founder) needs to hear this clearly:

> "You are not building a resume tool. You are building an outcome data business. The resume tool is how you get the data. This means Months 1-12, your primary metric is NOT revenue — it is outcome logging rate. Every feature that doesn't increase outcome logging is lower priority than one that does."
