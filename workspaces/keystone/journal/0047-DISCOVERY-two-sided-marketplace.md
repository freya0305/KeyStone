## DISCOVERY: Two-Sided Marketplace — B2B as Primary Revenue

**Slug**: two-sided-marketplace-pivot
**Type**: DISCOVERY
**Date**: 2026-05-03

## Discovery

User proposed a major pivot: KeyStone as a two-sided marketplace connecting employers (who need help writing JDs) and job seekers (who need help tailoring resumes).

### Key Insight

Instead of only helping job seekers optimize resumes, the platform can also help employers write better JDs — by analyzing public resumes to understand what good candidates look like, and using that to generate/improve JDs.

### Why This Solves Core Problems

1. **Cold Start**: Public resume + JD data available from Day 1 — no waiting for user data
2. **B2B > B2C**: Companies pay more willingly for recruitment tools ($99-499/month vs $12/month)
3. **Dual Data Flywheel**: Public data + employer JDs + job seeker resumes → continuous learning
4. **Reduced AI Dependency**: Training on public data instead of user-generated data

### Changes Required

| Original | New |
|---------|-----|
| B2C primary | B2B primary |
| $12/month users | $99-499/month employers |
| User outcome data | Public resume + JD data |
| Cold start 12-18 months | Day 1 data available |
| Single-sided | Two-sided network |
