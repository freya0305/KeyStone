## Correction to Journal Entry 0006

Entry 0006 concluded: "VMock has no confirmed SG university contracts; KeyStone has a 12-24 month window."

**This is factually incorrect.** The founding team has direct knowledge that VMock has already established cooperative relationships with Singapore universities. The "window period" framing is wrong.

## Revised Understanding

VMock is NOT an incoming competitor. It is an **existing incumbent** in the SG university career centre market. The competitive situation is therefore displacement, not greenfield.

This changes the strategic picture on several dimensions:

| Dimension | 0006 Framing (Wrong) | Revised Framing (Correct) |
|-----------|---------------------|--------------------------|
| Competitive situation | Greenfield — VMock not yet here | Displacement — VMock already present |
| Sales argument | "Sign before VMock arrives" | "Replace or complement VMock with outcome data they can't provide" |
| University mindset | No existing tool budget/habit | Existing VMock relationship (switching cost present) |
| Urgency driver | Time-to-first-mover | Data moat depth (time-to-irreversibility) |
| Primary risk | VMock arriving fast | VMock deepening existing SG relationships |

## What Doesn't Change

VMock's fundamental architectural gap remains: it scores against an ATS model, not against SG hiring manager actual callback behaviour. Career directors using VMock today cannot answer "did students who used it get better callback rates?" — because VMock doesn't collect outcome data.

This is the displacement argument: KeyStone doesn't need to arrive before VMock. It needs to be measurably better on the metric VMock cannot address.

## Implications for Strategy

1. **The moat is not timing — it is data depth.** The only defensible position against an incumbent is to build something structurally impossible for the incumbent to replicate without starting over: outcome-calibrated suggestion signals collected from Day 1.
2. **University conversations now require a displacement argument**, not a "we're the first one here" argument. The pitch must name VMock's gap directly and offer the metric VMock cannot: cohort-level callback rate improvement.
3. **First university acquisition is harder than previously assessed.** There is an existing relationship and likely an existing contract to displace (or a "this is good enough" inertia to overcome). The warm network prerequisite (0008) is now even more critical.
4. **The data moat strategy (journal 0010) is the ONLY long-term answer.** See separate journal entry.
