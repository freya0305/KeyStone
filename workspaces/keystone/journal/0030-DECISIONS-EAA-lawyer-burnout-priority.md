## Decision 1: EAA Legal Opinion — Accept Lawyer Recommendation

**Commitment**: Week 1-2 engage employment lawyer to obtain written EAA opinion letter.

### Alternatives Considered

- **Option A**: Skip EAA opinion — Rejected. Investor/corporate bank/university legal will ask.
- **Option B**: Full EAA compliance audit — Rejected. Overkill for MVP; low-risk product per Analysis 19.
- **Option C**: Written opinion letter only — **Selected**. SGD 500-1,500; sufficient for all downstream due diligence.

### Consequences

- Budget: SGD 500-1,500 one-time
- Timeline: Week 1-2
- Unblocks: Investor DD, corporate bank account, university contracts, Startup SG Tech application

## Decision 2: Burnout Priority — B2C and B2B Are Non-Negotiable

**Commitment**: B2C acquisition + B2B outreach are life-or-death priorities. All other tasks are secondary.

### Priority Matrix

| Priority | Activity | Why Non-Negotiable |
|----------|---------|-------------------|
| P0 (never cut) | B2C organic growth | Data collection engine — moat stops building if this stops |
| P0 (never cut) | B2B agency + university outreach | Primary revenue — no path to break-even if this stops |
| P1 (cut if overloaded) | Compliance (DPO, EAA letter) | Can delay 1-2 weeks |
| P1 (cut if overloaded) | Angel fundraising | Can defer to Month 3-4 if B2B is generating signal |
| P2 (delegate or cut) | LinkedIn organic content | Time-intensive, low immediate ROI |
| P2 (delegate or cut) | Reddit community management | Build once, then maintain |

### Consequences

- Founder focus protected for highest-leverage activities
- Delegation budget: SGD 900-1,800/month for contractors/VA
- If overloaded: Cut LinkedIn and Reddit first; preserve B2C + B2B

## Decision 3: Startup SG Tech Plan B — All Options Acceptable

**Commitment**: If Startup SG Tech is rejected or delayed >12 weeks, any/all of the following are acceptable:

| Option | Description | When to Use |
|--------|-------------|-------------|
| A) Self-fund | Personal savings | Gap < SGD 20K, delay < 3 months |
| B) Early angel | Accelerate angel conversations | Gap > SGD 20K OR delay > 3 months |
| C) Cut burn | Downgrade infra | Immediate cash preservation |
| D) Combine | A + B + C in sequence | Most realistic |

### Consequences

- No single contingency is catastrophic
- Do NOT let grant approval gate product or hiring decisions
- Apply Month 1, operate as if it won't be approved

## Decision 4: 2% Conversion Response — Strengthen B2B Data Exchange

**Trigger**: Month 3 conversion rate < 2.5%

**Response**: Shift B2C marketing effort to B2B agency partnerships — specifically data exchange arrangements.

### Rationale

- Agencies have employer-verified outcome data (placement records)
- KeyStone offers: "Your candidates get better resumes, you get anonymized placement analytics"
- Agencies provide: placement records with candidate consent
- PDPA-compliant if structured as service provision, not data sale

### Consequences

- If triggered: Pause Reddit/LinkedIn, double agency outreach
- Agency data pilot success (3-5× more outcome records) could shift primary data strategy
